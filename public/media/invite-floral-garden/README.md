# Иллюстрации шаблона «Цветочный сад»

Все четыре изображения созданы встроенным imagegen и сохранены как WebP для проекта.

- `garden.webp` — фотореалистичный широкий свадебный фон 16:9: белые розы, гортензии, эвкалипт и драпировка по краям, каменная колонна справа, размытый шалфейный сад в центре; без людей и надписей.
- `garden-mobile.webp` — вертикальная версия 9:16: белые цветы обрамляют оба края, свободный приглушённый центр под белые имена; без людей и надписей.
- `venue.webp` — неоклассическая светлая вилла с лестницей и белыми цветочными композициями, мягкий летний свет, горизонтальное фото; без людей и надписей.
- `story.webp` — пара со спины идёт за руки по саду усадьбы, платье цвета слоновой кости и тёмный костюм, репортажный свадебный стиль, вертикальное фото; без надписей.
