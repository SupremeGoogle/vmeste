# Богема — новые иллюстрации

Все пять изображений созданы для этого шаблона встроенным генератором изображений. Исходные изображения, графика и код сайта-референса не использовались.

| Файл | Задание генерации |
| --- | --- |
| `landscape.webp` | Панорамный акварельный средиземноморский сад: кипарисы слева, оливковое дерево справа, дальние горы, светлый центр для арочной карточки; кремовая, шалфейная и оливковая палитра; без текста и людей. |
| `floral-garland.webp` | Широкая прозрачная гирлянда из пионов, садовых роз, листьев и вьющихся стеблей в тоне старого золота; тонкая гравюрная линия, без текста и фона. |
| `veranda.webp` | Архитектурная фотография современной стеклянной свадебной веранды среди деревьев и газона при дневном свете; без людей и надписей. |
| `dress-women.webp` | Горизонтальная студийная подборка из шести женских вечерних образов в румяных, голубых, кремовых, шалфейных и шампанских оттенках; без текста и логотипов. |
| `dress-men.webp` | Горизонтальная студийная подборка из шести мужских образов: светлая рубашка, льняной костюм, оливковый костюм, тёмная рубашка, поло и серый костюм; без текста и логотипов. |

Конечные файлы оптимизированы в WebP для страницы приглашения.
