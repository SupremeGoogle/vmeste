# Шаблон «Жемчуг»

Две независимые фотографии созданы встроенным ImageGen и доступны для замены в визуальном редакторе:

- `couple.webp` — вертикальный свадебный портрет пары у озера Комо для овальной обложки;
- `venue.webp` — широкая фотография итальянской виллы у озера для единственного блока локации.

Оба запроса задавали фотореалистичную editorial-съёмку, светлую палитру айвори и шалфея, естественный мягкий свет, отсутствие текста, логотипов, рамок и водяных знаков. Исходные PNG сохранены в каталоге сгенерированных изображений Codex, а в проект добавлены оптимизированные WebP.
