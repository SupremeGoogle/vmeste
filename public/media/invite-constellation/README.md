# Созвездие — изображения шаблона

- `couple.webp` — фотография пары на обложке.
- `venue.webp` — фотография единственной локации.
- `dinner.webp` — фотография ужина для галереи.
- `moon-sculpture.webp` — созданная встроенным ImageGen объёмная стеклянная
  луна над тёмной водой. Используется как атмосферная арт-сцена в блоке
  истории; поверх неё живёт отдельная SVG-анимация кометы и кристаллов.

Изображения созданы отдельно и независимо заменяются в визуальном редакторе.

Промпт новой арт-сцены: кинематографичная 3D-композиция с парящей
полупрозрачной стеклянной луной, шампанским металлом, отражением в ночной
воде, объёмным светом и глубоким пространством; без текста, логотипов,
интерфейса, колец и плоской векторной графики.
