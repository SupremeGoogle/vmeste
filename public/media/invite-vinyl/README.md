# Медиа шаблона «Винил»

Обложка шаблона живая: три плитки — короткие анимированные WebP,
две оставшиеся картинки статические. Всё это образцы: организатор
меняет их на свои снимки прямо в редакторе.

| файл | что это | откуда |
|---|---|---|
| `walk.webp` | пара идёт по саду, 2,2 с, 24 кадра | кадр из свободного стока Mixkit (Mixkit Free License: коммерческое использование без указания авторства) |
| `portrait.webp` | пара в кадре, 2,2 с | там же |
| `floor.webp` | танцпол в неоне, 2,4 с | там же |
| `first-dance.webp` | первый танец, статичный кадр | StockSnap, лицензия CC0 |
| `banquet.webp` | накрытые столы, статичный кадр | StockSnap, лицензия CC0 |
| `kiss.webp` | поцелуй молодожёнов | StockSnap, лицензия CC0 |
| `sunlight.webp` | пара в контровом свете | StockSnap, лицензия CC0 |

Анимации собраны из видео так:

```bash
ffmpeg -ss 0.5 -t 2.2 -i clip.mp4 -vf "fps=11,scale=360:-2:flags=lanczos" \
  -loop 0 -c:v libwebp -q:v 55 -compression_level 6 walk.webp
```

Почему WebP, а не GIF: те же кадры весят втрое меньше (223 КБ против
примерно 700 КБ), а в `<img>` ведут себя ровно так же — цикл без кнопок.
Свои гифки организатор при этом загружать может: обычный GIF проходит
через тот же загрузчик фотографий.
