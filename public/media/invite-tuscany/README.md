# Шаблон «Тоскана»

Три независимые фотографии созданы встроенным ImageGen и доступны для замены в визуальном редакторе:

- `couple.webp` — вертикальный портрет пары на фоне тосканских холмов;
- `venue.webp` — широкая фотография одной виллы среди кипарисов и оливковых рощ;
- `dinner.webp` — вечерний ужин при свечах во дворе той же виллы.

Запросы задавали фотореалистичную editorial-съёмку, палитру шоколада, терракоты, пергамента и приглушённой зелени, тёплый кинематографичный свет, отсутствие текста, логотипов и водяных знаков. Исходные PNG сохранены в каталоге сгенерированных изображений Codex, в проект добавлены оптимизированные WebP.
