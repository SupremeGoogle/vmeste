# Сердце к сердцу — оригинальные изображения

Фотографии созданы заново для этого шаблона. Код, изображения и графика с сайта-образца не использовались. Векторная фактура бумаги создана отдельно в `paper.svg`.

- `hero.webp`: пара в льняной одежде лежит рядом на лугу в тёплом вечернем свете.
- `venue.webp`: стеклянная свадебная веранда среди леса у озера.
- `dresscode.webp`: шесть вечерних женских образов в мягкой природной палитре.
- `dresscode-men.webp`: шесть мужских образов в той же палитре.
- `story-1.webp` — `story-6.webp`: оригинальные сцены детства, знакомства, вечера, путешествия и предложения. Получены из сгенерированной сетки и обрезаны в отдельные карточки.

Изображения подготовлены в WebP для быстрой загрузки приглашения.
