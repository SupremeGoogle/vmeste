# Медиа шаблона «Акварель»

Заставка использует оригинальную предметную иллюстрацию, созданную для
этого шаблона. Фотографии-образцы в приглашении заменяются своими в
редакторе.

| файл | что это | откуда |
|---|---|---|
| `stationery-intro.webp` | акварельная бумага, конверт и атласная лента на заставке | оригинальное изображение, создано генератором изображений OpenAI |
| `couple.webp` | обмен кольцами | StockSnap, лицензия CC0 |
| `venue.webp` | накрытый стол на площадке | StockSnap, лицензия CC0 |
| `celebration.webp` | поздравления гостей | StockSnap, лицензия CC0 |
| `rings.webp` | пара крупным планом | StockSnap, лицензия CC0 |
| `bench.webp` | молодожёны на скамейке в закатном свете | StockSnap, лицензия CC0 |
| `veil.webp` | кадр под фатой, чёрно-белый | StockSnap, лицензия CC0 |
| `bouquet.webp` | невеста с букетом | StockSnap, лицензия CC0 |
