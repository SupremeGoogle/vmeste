# Медиа шаблона «Лилия»

Волны между полосами, контурные лилии и кнопка воспроизведения нарисованы
в CSS и SVG. Здесь лежат только фотографии-образцы — организатор меняет их
на свои в редакторе.

| файл | что это | откуда |
|---|---|---|
| `couple.webp` | пара на скамейке в закатном свете | StockSnap, лицензия CC0 |
| `venue.webp` | накрытые столы на площадке | StockSnap, лицензия CC0 |
| `women.webp` | три образа для девушек: олива, шалфей, песок | встроенный генератор изображений (gpt_image_2_5), 5 октября 2026 |
| `men.webp` | три мужских костюма: олива, лён, тёмный изумруд | встроенный генератор изображений (gpt_image_2_5), 5 октября 2026 |

Образы дресс-кода сгенерированы под палитру шаблона (олива, шалфей, песок, сливочный, тёмный изумруд): вымышленные люди в саду, без текста и логотипов. Прежние снимки со StockSnap не совпадали с палитрой.
