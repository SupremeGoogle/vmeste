# «Искра»

Дизайн по локальному видео-референсу `11111111.MP4`: бордовая коробочка,
фотополоска, светлая записка с неровным краем, рукописные заголовки.
Декор и открытие коробочки — собственные HTML/CSS/SVG, без внешних скриптов.

Фотографии-примеры скопированы из имеющихся локальных шаблонов проекта:
`couple.webp` — prism/couple.webp, `portrait.webp` — roseraie/portrait.webp,
`kiss.webp` — roseraie/hero.webp, `venue.webp` — bohema/veranda.webp,
`dress.webp` — burgundy/dress.webp. Организатор заменяет их в общем редакторе.

Каркас соответствует `docs/template-standard.md`. Виш-лист добавляется общим
реестром скрытым; анкета использует общий рендер и маршруты ответа гостей.
Образец: `/templates/iskra`.
