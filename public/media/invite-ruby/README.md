# Рубин — изображения шаблона

- `couple.webp` — отдельная фотография пары для обложки.
- `venue.webp` — отдельная фотография единственной локации.
- `rose-stem.webp` — реалистичная роза со стеблем на прозрачном фоне.
- `rose-cluster.webp` — угловая композиция из роз и лепестков на прозрачном фоне.
- `background.webp` — фоновая композиция из шёлка, бордовых лент и живых роз.

Фотографии пары и локации созданы специально для шаблона и заменяются независимо в редакторе. Флористика и фон также созданы отдельно, поэтому не зависят от пользовательских фотографий.
