## Что проверено

- Создание и публикация нескольких мероприятий; настройка времени и меню; импорт CSV с предварительным просмотром и объединением повторов; применение шаблона приглашения.
- Именные ссылки, ответы 40 гостей, спутники, сводка кухни и выбор блюд.
- Создание столов и рассадка 39 гостей; два одновременных изменения одного плана. Обнаружена и исправлена гонка: теперь один запрос проходит, второй получает HTTP 409 и актуальный план.
- Печать PDF, поиск гостя по QR, загрузка и модерация шести фотографий, экран в зале, розыгрыш с повторяемым результатом, архив и отзыв гостевых ссылок.
- Разделение организаций, закрытие чужих страниц и API, отсутствие доступа по поддельным токенам, правила кеширования и индексации, ограничения на фото и размер гостевых страниц.
- Все 21 шаблон открываются как HTML; ссылки на локальные изображения и шрифты, обнаруженные в разметке, отвечают HTTP 200.
- Девять примеров оскорблений, угроз и злых пожеланий отклоняются; число записей в базе не увеличивается. Обычное пожелание попадает в очередь ручной модерации и не публикуется сразу.
- Для медленных разделов добавлены экраны загрузки: гости, приглашение, фотографии, печать, формы, ответы, пожелания и экран зала.

## Границы проверки

- По просьбе пользователя генерация видео не запускалась и не проверялась.
- Автоматическая проверка шаблонов подтверждает ответ страницы и доступность ресурсов. Визуальный осмотр каждого шаблона и его работы на разных экранах не выполнен: управление локальным сайтом через браузер в этой среде было заблокировано политикой инструмента.
- Фильтр пожеланий покрывает проверенные явные оскорбления и угрозы. Скрытый негатив или новые формулировки могут пройти предварительный фильтр; все принятые сообщения всё равно требуют ручного одобрения перед показом на экране.

## Повторный запуск

После запуска приложения на порту 3010 с отдельной базой `vmeste_liveqa`:

```powershell
npm test
npm run lint -- --quiet
npx tsc --noEmit
$env:BASE='http://localhost:3010'; python scripts/rehearsal.py
$env:BASE='http://localhost:3010'; python scripts/access-check.py
$env:BASE='http://localhost:3010'; npx tsx scripts/live-qa-smoke.ts
```

Для последней команды `DATABASE_URL` должен указывать на `vmeste_liveqa`; сценарий откажется работать с другой базой.
