# Промо-ролик «Вместе» — передача дел

Документ для нового чата. Всё, что решено и сделано по рекламному ролику vvvmeste.com,
и что осталось: **блок продукта (моушн-графика) и озвучка**.

## 1. Что уже есть

- **Стиль ролика:** мультяшный 3D (как полнометражные анимационные фильмы), в одном стиле
  с маскотом — белой пушистой птичкой с бордовым бантом (`public/media/mascot/`).
- **Формат:** 16:9, 1920×1080, 24 fps.
- **Звук:** **без музыки**, только звуковые эффекты. Фон (комната, улица, ветер) не должен
  обрываться на склейках — микро-кроссфейды 2–4 кадра. Единственная намеренная тишина —
  перед пробуждением героини.
- **Все игровые сцены сгенерированы** (Higgsfield, модель Kling 3.0 Omni / Kling Frames).
  Список клипов с прямыми ссылками — `clips.txt`, скачать — `bash fetch_clips.sh`.
- **Черновой монтаж** собирается скриптом `rough_cut.py` (ffmpeg) из папки `video/`.
  Сейчас он длится ~3:36 — нужно ужать до ~2:00 (в основном фазы дня).
  Перед запуском собрать монтаж дверей (см. раздел 6).
- **ID всех картинок и видео в Higgsfield** — `higgsfield-ids.md` (персонажи, локации,
  ключевые кадры — пригодятся как референсы).
- **Голос НЕ сгенерирован.** Блок продукта НЕ сделан — вместо него в черновике заглушка 3 с.

## 5. Higgsfield — уроки (важно, сэкономит кредиты)

- Баланс на момент передачи ~100 кредитов. Kling Omni 15 с pro со звуком = 30,
  10 с = 20, 5 с = 10; Kling Frames std 3 с = 3,75; картинка Nano Banana 2.1 = 2.
- `multi_prompt` — список объектов `{"prompt": "...", "duration": N}`, N — **целое**.
- Kling Frames (`kling_o3_flf`) с `multi_shots` **падает** — для многокадровых использовать
  `kling_o3_image_reference` (до 7 референсов, без start_image).
- Загруженные вручную картинки как референс для Kling падали — лучше передавать ID
  картинок, сгенерированных в Higgsfield.
- Пакетная отправка видео иногда даёт ложное «Out of credits» — отправлять по одной.
- Фильтр «nsfw» ложно срабатывает на некоторые формулировки (например «cherry-red
  door») — перефразировать.
- Пользователь требует **мега-подробные** промпты: посекундно, где кто стоит, что в какой
  руке, откуда берётся предмет; героиня всегда в кадре; конверт передаётся из рук в руки;
  получатель сначала с пустыми руками. Три разные сумки Kling стабильно не удерживает.

```bash
cd video && i=0; in=""; fc=""; for n in 01 02 03 04 05 06 07 08 09 10; do in="$in -ss 0.9 -t 1.0 -i door$n.mp4"; fc="$fc[$i:v]scale=1920:1080,setsar=1,fps=24,format=yuv420p[v$i];[$i:a]aresample=48000,aformat=channel_layouts=stereo,afade=t=in:d=0.03,afade=t=out:st=0.97:d=0.03[a$i];"; i=$((i+1)); done; c=""; for j in $(seq 0 9); do c="$c[v$j][a$j]"; done; ffmpeg -y $in -filter_complex "${fc}${c}concat=n=10:v=1:a=1[v][a];[a]loudnorm=I=-18:TP=-1.5[an]" -map "[v]" -map "[an]" -c:v libx264 -crf 18 -c:a aac DOORS_10x1s.mp4
```
